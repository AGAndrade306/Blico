# Comandos que o Blico entende

Entendidos por regras, sem modelo e sem internet. Variações comuns funcionam ("pra", "para o", "por favor", "Blico, ...").

| Você fala | O que acontece |
| --- | --- |
| "manda pro João que eu chego em 10 minutos" | Abre a conversa do João no WhatsApp com o texto pronto. Você toca em enviar. |
| "manda mensagem pra Ana" | Abre a conversa da Ana. Se houver duas Anas, o cartão pergunta qual. |
| "liga pra mãe" | Abre o discador com o número. Você toca para ligar. |
| "pede um uber pra casa" | Abre o Uber com o destino preenchido (cadastre casa e trabalho no app). |
| "chama um 99" | Abre o 99. |
| "pede uma pizza no iFood" | Abre o iFood. |
| "toca Djavan" | Procura no Spotify. |
| "me leva pro aeroporto", "como chego no shopping" | Navegação no Google Maps. |
| "me acorda às 7", "alarme para seis e meia", "8 da noite" | Cria o alarme. |
| "timer de 5 minutos", "cronômetro de meia hora" | Inicia o timer. |
| "pesquisa preço do dólar" | Pesquisa na internet. |
| "abre a câmera" | Abre qualquer app pelo nome. |

O que não está na lista vai para a nuvem, se o servidor estiver configurado na tela inicial do app. A nuvem pode escolher uma das ferramentas acima (com as mesmas regras de confirmação) ou responder uma pergunta em voz alta ("quem escreveu Dom Casmurro?"). Antes de sair do aparelho, nomes de contatos, telefones, e-mails e endereços salvos são trocados por apelidos e restaurados na volta. Sem servidor configurado, a resposta continua sendo "Ainda não sei fazer isso".
